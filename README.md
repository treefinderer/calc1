# Tally Calculator

A one-page desk calculator with order of operations, percent, keyboard shortcuts and a tape of results. Plain HTML, CSS and JavaScript, no build step: markup in `index.html`, styles in `style.css`, and scripts in `common.js` (shared helpers), `calc.js` (calculator, tape and radio), `weather.js` and `news.js`. Run the tests with `tests/run.sh` (headless Chrome), or open `/tests/` on a local server.

Plays the free, listener-supported [Radio Paradise](https://radioparadise.com/) Rock Mix stream once you press a key, with a Mute button.
